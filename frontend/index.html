      Noch keine Apps

      Trag oben ein Repository ein, dessen Releases eine App enthalten, etwa pklaschka/feldspur von GitHub oder codeberg.org/owner/name von Forgejo und Gitea. Die Liste gilt auf all deinen Macs, installiert wird auf jedem Mac einzeln.

      Hast du schon eine Liste, etwa von einem anderen Rechner oder aus deinem Team? Dann übernimm sie als Katalog.

      Auf deinen anderen Macs bleibt die App installiert. Nur die gemeinsame Liste ändert sich.
